自我提升与价值观的偷渡

从忒修斯之船到写作的阅读量，辨认自我提升建议里藏着的成功标准，以及它怎样改变我们做事的理由。

Nov 10, 202610 min read
Original source · More To That

文章信息 作者：Lawrence Yeo
材料：英文原文
主题：自我提升、行动动机、价值排序、目标与指标

这篇文章想回答什么？

核心判断 学习别人的方法时，要留意建议是否也替你选定了目标。一旦外来的成功标准开始主导日常取舍，做这件事的理由也会跟着变。

Lawrence Yeo 从忒修斯之船追问，人们为什么愿意一块块换掉船板？在他的读法里，雅典人想保留一艘能纪念忒修斯的船，这个意图使每一次修补都有方向。同样，一个人可以更换工具、重排日程、练出新的本领，同时继续做自己原本珍视的事。开始改变做法之后，还可以追问谁在决定应该朝哪里改。

这个问题在自我提升内容里很具体。一份建议可以解决你眼下的困难，也可以顺手告诉你，什么样的结果才配叫进步。比如，为了让一篇文章写出来，你学会了定时动笔。接着，你又开始用浏览量判定每一次写作的成败。这两步看起来都在帮助你写作，却在回答两个不同的问题。前者解决卡在哪里，后者决定写作服务于什么。原文的贡献，是让第二个问题在我们接受建议时变得可见。

核心观点

  1. 在 Yeo 对忒修斯之船的读法里，修补之所以有方向，是因为人们知道自己想保留什么。

    • 最后一块旧木板换掉后，它还是原来的船吗？Yeo 把注意力移到修船的人身上。只要保留纪念物仍有意义，修补就能延续同一个意图。反过来，假如最后是为了把船送给一个大家并不在意的人，修得再像，原来做这件事的理由也已经消失。作者用这组对照说明，外观与做法的连续，可以和目的的变化同时发生。
    • 这个比喻提供的是检查变化的角度。放到个人生活里，重要的是分辨自己在改变哪一层。换写作软件、调整作息或改掉一个旧习惯，对自我认同的影响，未必和改变写作、工作或交友的理由一样大。

  2. 资源、做法和优先级是三种不同的变量，遇到困难时可以分开诊断。

    • Yeo 借用 Clayton Christensen 的组织能力框架。资源是手里有什么，流程是怎么把它用起来，优先级是资源有限时先顾哪一头。以写文章为例，资料和可支配时间是资源，安排阅读、列提纲、改稿是流程，想把问题弄懂、服务读者还是扩大传播，则属于目的和优先级。这三种目的可以并存，差异会在它们开始争夺同一个下午时显出来。
    • 这个区分有一个直接用途。缺一篇关键资料，可以补资源。资料齐全却迟迟动不了笔，可以改流程。如果写完已经达到原来的目的，却因为没涨关注就觉得整件事白做了，需要检查的是衡量成败的标准是否变了。把三种困难都归为不够努力，很容易用更多时间和工具去处理一个本来需要重新作判断的问题。

  3. 一项建议开始替你定义成功时，方法里就已经带上了价值判断。

    • 原文虚构了一个想写冥王星的博主。他对题目感兴趣，却卡在组织材料和开头。每天定时写一点，能直接帮助他开始。一本写作书随后把扩大读者规模放到中心，建议看似仍然在谈写作，却预设了写作首先是为了触及更多人。博主一旦接受这条前提，就可能从题目、标题到叙述方式都重新考虑，甚至在读者很少时怀疑文章还有没有必要写。
    • 扩大传播本身可以是正当的目标。问题在于，读者可能只想学一项技巧，却连同它背后未经讨论的优先级一起接收了。把建议翻译成它对成功的定义，往往就能看见其中的价值判断。固定写一百字可以服务于好奇心，也可以服务于增粉，真正决定文章方向的是你用哪件事判断它值不值得写。

  4. 价值排序会通过一次次资源分配生效，日常的小调整因此可能累积成方向的变化。

    • Yeo 转述戴尔与华硕的外包故事，区分了委托生产零部件、把设计和供应链等流程交出去，以及用短期财务表现重新判断哪些能力值得保留。在他的分析里，改变评估标准会影响前两种决定的方向。这个管理案例适合用来理解优先级如何影响资源分配。戴尔的市场表现需要更多证据才能解释。
    • 同样的观察可以用在个人项目里。偶尔参考一篇文章的阅读量，可能只是了解传播效果。如果一段时间里只有阅读量增长才算赢，就会逐步少写难解释的题目，少做耗时的核对，也更愿意重复已经有效的选题。这是从原文延伸出来的判断。最能暴露优先级的，是目标发生冲突时你反复放弃了什么。

  5. 一项追求可以由他人启发，是否值得成为自己的目标，需要经过经验和取舍。

    • Yeo 最强调的是亲身经验。别人可以提供一个值得考虑的理由，但只有自己做过、观察过后果，才知道它是否值得为之投入。原文把借用别人的理由写得很危险。更有用的读法是把来源和认同分开，因为原文自己也承认，价值观会受成长环境和人际关系塑造。被一个人影响之后，我们依然可以问清楚自己接受了哪些部分、有哪些保留，以及遇到冲突时准备怎样选择。
    • 回到博主的例子，他原本只想满足好奇心，也可能后来发现，和陌生读者讨论能让他看见自己遗漏的问题，于是愿意多花时间解释背景。这是一种经过经验修正的价值排序。如果唯一变化是他开始害怕没人看，连自己喜欢的题目都不敢写，同样的增长目标就有了另一种含义。值得保留的是重新评价目标的能力。

  6. 采用新方法前，先写下要解决的问题、成效如何判断，以及哪些代价可以接受。

    • 原文主张多接触可用的工具和方法，对替你解释为什么该这样生活的建议多留一步判断。把它落实到一个项目里，可以先为自己写下具体目的。例如，做读书笔记是为了几周后仍能复述原文的论证，所以先看能否讲清主要结论、依据和边界。更新频率可以帮助形成节奏，阅读量可以反映一部分传播情况，各自有用途。
    • 一个实际的试法是给新建议设一个小范围。连续几次按固定时段写作，然后同时检查产出与原始目的。要是写得更快、理解也更深，可以继续用。要是只是发表得更多，却没有留下能复述的东西，就回头调整做法或衡量标准。这样也给目标的变化留了位置。想从自用笔记转向公开写作时，可以明确承认自己增加了服务读者的目标，再决定怎样平衡两种需要。

外部资料补充

Christensen 与 Overdorf 的框架解释了，为什么公司即使具备资金和人才，也可能因惯用流程或机会筛选标准而做不了某件事。Yeo 把这套框架移到个人身上时，还提出了一个关于身份的问题。哪些变化会让我们觉得一个人和过去大不相同？Strohminger 与 Nichols 的五项实验发现，参与者很看重道德品格的改变，自传性与情绪记忆也有分量。前者解释组织如何选择，后者描述人们如何判断身份的连续性。两者都能帮助理解为什么原则的变化可能格外显眼，个人身份仍然包含原则之外的因素。Christensen 与 Overdorf，组织能力框架 · Strohminger 与 Nichols，The Essential Moral Self

即便原则很重要，目标来自别人，也并不决定它会以什么方式影响自己。Ryan 与 Deci 的自我决定理论区分了两种体验。一种是为了奖励、避免责备，或为了压住内疚而做。另一种是理解了目标的意义，也愿意把它纳入自己的其他追求。Sheldon 与 Elliot 的纵向研究进一步发现，与个人兴趣和核心价值较一致的目标，和较持续的努力、较高的达成可能性相关，达成后也往往伴随更大的幸福感收益。这让原文的提醒更精确。分辨一个目标有没有被偷渡，先问我是在回应压力，还是经过考虑后愿意为它投入。这类研究支持把动机的质量当作判断线索，具体目标是否值得追求仍需结合处境。Ryan 与 Deci，自我决定理论 · Sheldon 与 Elliot，自我一致目标的纵向研究

认可目标之后，仍然需要看看日常反馈实际鼓励了什么。Steven Kerr 从组织案例出发，指出人可能越来越多地做能被奖励的事，即使制度设计者口头上期待的是别的结果。这给原文的写作故事补上了一个机制。口头说希望理解得更深，却只为发文次数或点击量喝彩，行动很可能逐渐向这些数字靠拢，哪怕当事人依然真心重视理解。当查证要多花半天、会拖慢更新时，实际选择会揭示哪个标准更有分量。Kerr 的文章讨论的是组织里的奖励错配，这里的个人写作是对其思路的应用。Kerr，On the Folly of Rewarding A, While Hoping for B，1995 年修订版

关键概念

  • 价值排序　几个理由同时成立、资源却有限时，愿意优先照顾哪个理由，以及准备承受什么代价。它在具体取舍里比在自我描述里更容易观察。
  • 价值观的偷渡　建议表面解决做事的方法，暗中把某种成功定义一并带进来。判断时要看建议预设的成效和你原本的问题是否一致。
  • 内化　人理解并逐渐认同原先由外界提出的要求或目标，使它成为自己愿意承担的理由。
  • 自我一致的目标　与个人正在形成的兴趣和较核心的价值相吻合的目标。它可以费力，仍然值得自己投入。
  • 替代指标　用一个可观察的数字估计较难直接衡量的目标。发文次数可以帮助观察练习频率，几周后能否复述论证则更接近笔记有没有被消化。

值得继续追踪

  1. Christensen、Allworth 与 Dillon 的个人决策框架。追踪每天的时间与精力分给了什么，看看实际分配和自认重视的事情相差多远。How Will You Measure Your Life?
  2. 同一项要求何时会被主动认同。比较解释理由并提供选择的情境，和靠奖惩或羞愧感推动的情境，看看监督结束后人们是否还愿意继续。
  3. 读书笔记从私下保存到公开发布时，成功标准怎样变。值得分别记录自己能否回忆论证，以及读者能否顺利理解、查到依据。两种反馈有重合，也可能要求不同的取舍。

最后记住这件事

以后想起忒修斯之船，先想雅典人为何还愿意继续修。材料一直在换，一项活动却仍可能由同一个理由贯穿。看自己的变化也可以用类似的问法。遇到卡顿，先分清缺的是资源、顺手的做法，还是一个自己愿意认可的方向。前两种问题往往可以直接向别人请教，第三种需要结合自己的处境决定。

建议开始规定什么算成功时，这个标准就可能改变此后的取舍。别人提出的目标当然可以接受，前提是自己理解它的意义，也愿意承担它的代价。下次试一条自我提升建议时，可以先写一句我想改善什么，又愿意保留什么，再看实践结果。做得更快固然值得记录，知道这份效率最终用在什么地方，才有办法判断方法适不适合自己。
